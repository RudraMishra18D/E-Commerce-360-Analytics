End-to-End E-Commerce Data Analytics Project using MySQL and Power BI featuring Sales Analysis, Customer Intelligence, RFM Segmentation, Orders and Payment Analytics.
# 🛒 E-Commerce 360° Analytics

### End-to-End Data Analytics Project | MySQL + Power BI

An end-to-end E-Commerce Data Analytics project that transforms transactional data into actionable business insights using MySQL, Power BI, DAX, and data visualization.

## 🛠️ Technologies Used

* MySQL & MySQL Workbench
* Microsoft Power BI
* DAX (Data Analysis Expressions)
* Power Query
* Data Modeling
* SQL

## 📂 Dataset Overview

The project contains five interconnected tables:

| Table         |    Records |

| Customers     |      2,000 |
| Products      |        100 |
| Orders        |      5,000 |
| Order Details |     12,536 |
| Payments      |      5,000 |
| **Total**     | **24,636** |

## 📈 Power BI Dashboards

### 1. Executive Sales Overview

* Revenue and profit analysis

* Top-selling products

### 2. Customer Intelligence

* Active and repeat customers
* Customer retention analysis
* New vs. returning customers
* Top valuable customers
* RFM customer segmentation

### 3. Orders & Payment Analytics

* Total and delivered orders
* Delivery success rate
* Order status distribution
* Payment method analysis
* Monthly order trends
